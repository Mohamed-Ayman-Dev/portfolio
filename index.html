04 / Architecture

Architecture and code.

Feature-first Clean Architecture with BLoC/Cubit — how the production apps are structured.

lib/ (project root) 

      

      

        

          
Separation of concerns

          
UI knows nothing about APIs. It only reacts to typed state objects — swapping the data source requires zero UI changes.

        

        

          
Crash-proof networking

          
ApiResult<T> makes failure a first-class citizen. The compiler forces both success and error paths to be handled — no silent swallows.

        

        

          
Modular dependency injection

          
Each feature owns its DI registration. Adding a new feature is one class plus one line in the global locator. Nothing else changes.

        

        

          
Testable by design

          
Constructor injection across all layers means any dependency can be swapped for a mock. No framework needed for unit tests.

        

        

          
Single source of truth

          
Endpoints, error messages, and design constants live in one place each. A backend URL change is a one-line edit.

        

        

          
Scalability first

          
Feature-first folders mean adding orders or notifications never touches existing features.
